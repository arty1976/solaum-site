# 솔라움 홈페이지

[www.solaum.co.kr](https://www.solaum.co.kr) 의 소스입니다. GitHub Pages(main 브랜치 루트)로 배포됩니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 한국어 사이트 (CSS·JS 내장, 글꼴은 jsDelivr의 Pretendard) |
| `en/index.html` | 영어 사이트 (같은 디자인, 헤더의 KO/EN 버튼으로 전환) |
| `img/` | 회사 CI 로고(PNG, 흰색 버전 포함)와 콘셉트 렌더링 이미지(WebP, 800px·원본 두 크기). `-en`이 붙은 파일은 이미지 속 설명을 영어로 바꾼 영어판용 |
| `og.png`, `og-en.png` | 카카오톡·SNS 링크 공유 썸네일 (1200×630, 한국어·영어) |
| `favicon.png`, `apple-touch-icon.png` | 브라우저 탭·홈 화면 아이콘 (CI 심볼) |
| `CNAME` | 사용자 도메인 설정 (`www.solaum.co.kr`) |

`main` 브랜치에 변경을 올리면 보통 1~2분 안에 사이트에 반영됩니다.
